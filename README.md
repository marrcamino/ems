# EMS — Environmental Management System

An internal Environmental Management System (EMS) for **DENR-PENRO Dinagat Islands**, built to track and monitor the office's environmental resource consumption and compliance in line with ISO 14001:2015.

## Deployment

This system runs **offline**, hosted on a single on-premise server within the DENR-PENRO Dinagat Islands office network (LAN only — no internet access required or expected).

## Features

- **Fuel** — consumption tracking
- **Electricity** — consumption tracking
- **Water** — consumption tracking
- **Paper** — consumption tracking
- **ESWM** — Ecological Solid Waste Management (RA 9003) monitoring
- **GHG** — Greenhouse Gas emissions tracking

## Tech Stack

- SvelteKit
- TypeScript
- Tailwind CSS
- shadcn-svelte

## Getting Started

Install dependencies:

```bash
npm install
```

Run the dev server:

```bash
npm run dev
```
